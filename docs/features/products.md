# Products & Services

Maintain a catalog of the products and services you offer. When adding line items to an invoice or quote, you can pick from the catalog to auto-fill the description, price, unit, and tax rate.

## Product Fields

| Field | Description |
|-------|-------------|
| **Name** | Product or service name (required) |
| **Description** | Detailed description |
| **SKU** | Stock keeping unit code |
| **Unit Price** | Default price per unit |
| **Unit** | Unit type — piece, hour, day, kg, meter, lump sum, or custom |
| **Category** | Service, goods, subscription, or custom categories |
| **Tax** | Default tax rate applied when adding this product to an invoice |
| **Active** | Whether the product appears in the catalog |

## Categories

Create custom categories to organize your products. Categories are managed from the **Product Settings** page.

## Units

Define custom unit types beyond the built-in options (piece, hour, day, kg, meter, lump sum). Manage units from the **Product Settings** page.

## Deactivation

Products used on existing invoices cannot be deleted. Instead, deactivate them to hide them from the catalog. Deactivated products can be reactivated at any time.

## CSV Export

Export your product catalog as a CSV file.
